# Industry Classification Codes for B2B Targeting

## Overview

Industry classification codes are the backbone of B2B segmentation, enabling precise targeting, ICP matching, and compliance-aware outreach. LeadReach supports three major classification systems — SIC, NAICS, and GICS — plus a custom LeadReach Industry Tag system designed for modern B2B selling scenarios. This document provides comprehensive code tables, mapping relationships, and practical guidance for using classification codes in lead generation workflows.

### 4.3 Tag Assignment Algorithm

```yaml
tag_assignment:
  inputs:
    - naics_primary: Primary NAICS code from enrichment
    - naics_secondary: Secondary NAICS codes
    - sic_codes: SIC codes from data providers
    - gics_classification: GICS sub-industry if available
    - website_keywords: Technology/product keywords from website
    - product_description: Product/service description
    - funding_data: VC/PE funding category
  
  rules:
    - exact_naics_match: If NAICS matches tag range exactly → assign tag (confidence: 0.95)
    - keyword_match: If website contains tag-specific keywords → assign tag (confidence: 0.80)
    - product_match: If product description matches tag description → assign tag (confidence: 0.75)
    - funding_category: If funding category (e.g., "fintech") matches tag → assign tag (confidence: 0.85)
    - composite_score: Average confidence across all signals → assign if ≥ 0.70
  
  multi_tag:
    - allow_up_to: 3 primary tags per account
    - primary_tag: Highest confidence score
    - secondary_tags: Confidence 0.70-0.95
    - tertiary_context: Confidence 0.50-0.70 (used for enrichment only)
```

## 10. Implementation in LeadReach

### 10.1 Classification Pipeline

```yaml
classification_pipeline:
  step_1_enrichment:
    - source: data_providers (ZoomInfo, Apollo, Clearbit)
    - extract: naics_primary, naics_secondary, sic_codes, employee_count, revenue
  
  step_2_classification:
    - naics_to_tag: Map NAICS to LeadReach Industry Tags
    - sic_to_tag: Map SIC to LeadReach Industry Tags
    - gics_to_tag: Map GICS to LeadReach Industry Tags
    - confidence_score: Calculate confidence for each mapping
  
  step_3_enrichment_supplement:
    - website_analysis: Scrape website for industry keywords
    - product_analysis: Analyze product descriptions for vertical signals
    - job_postings: Analyze open roles for industry signals
    - funding_data: Cross-reference with Crunchbase/AngelList categories
  
  step_4_icp_mapping:
    - tag_to_icp: Map LeadReach Tag to ICP profile
    - pain_point_inference: Infer likely pain points from industry
    - compliance_requirements: Apply industry-specific compliance controls
    - budget_authority: Estimate budget authority from industry + company size
  
  step_5_output:
    - primary_tag: LeadReach Industry Tag (highest confidence)
    - secondary_tags: Up to 2 additional tags
    - icp_score: ICP match score based on industry + other signals
    - compliance_flags: Regulatory requirements to apply
    - outreach_strategy: Recommended outreach approach by vertical
```

### 10.2 Data Quality Rules

- **NAICS validation**: Verify NAICS codes are valid 2022 edition codes
- **SIC cross-reference**: Cross-check SIC codes against NAICS mappings
- **Conflict resolution**: When SIC and NAICS suggest different industries, prefer NAICS (more current)
- **Confidence thresholds**: Require ≥0.70 confidence before assigning LeadReach Tag
- **Manual review queue**: Flag classifications below 0.70 confidence for human review
- **Update frequency**: Re-classify accounts quarterly as enrichment data refreshes
