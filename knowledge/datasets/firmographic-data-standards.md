# Firmographic Data Standards

Firmographic data standards define the structured attributes used to classify and segment business organizations. Core firmographic dimensions include: company size (employee count ranges: 1-10, 11-50, 51-200, 201-500, 501-1000, 1001-5000, 5001-10000, 10000+), revenue range (under $1M, $1-10M, $10-50M, $50-100M, $100-500M, $500M-1B, $1B+), industry classification (SIC, NAICS, and custom LeadReach taxonomy mapping), geographic footprint (headquarters country, operating countries, regional presence), and organizational structure (public/private, subsidiary/parent, number of locations). Advanced firmographic attributes include: technology stack (identified via technographic signals), growth indicators (hiring velocity, funding history, revenue trajectory), and buying propensity models (predictive scores based on firmographic patterns). Data quality standards require: 95%+ completeness for core attributes, 90%+ accuracy verified quarterly, and real-time enrichment triggers for records missing key attributes. LeadReach agents use firmographic standards to: classify prospects into ICP segments, apply segment-specific outreach strategies, and enrich incomplete records via multi-source data aggregation.
